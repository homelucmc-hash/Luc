# Val Thorens — téléchargement

Cette branche fournit une copie portable du site d’inspiration Là-haut.

Téléchargez `val-thorens.zip`, décompressez-le puis ouvrez `Val-Thorens.html` dans un navigateur moderne. Les images, les polices et le code sont intégrés. Aucun serveur ni aucune installation ne sont nécessaires. Le relief 3D nécessite WebGL et dispose d’une illustration de secours.

Ce site indépendant n’est pas le site officiel de Val Thorens. Aucun secret ni identifiant n’est inclus.
