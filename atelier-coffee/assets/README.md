# Sources de l'animation ATELIER COFFEE

- **Source actuelle : `espresso-live-action.mp4`.** Prise de vue réelle fournie par l'utilisateur dans GitHub, initialement nommée `15157920_3840_2160_24fps (1).mp4`. Le renommage conserve les octets du fichier original. Vidéo H.264 3840×2160, 24 images/s, 542 images, durée 22,583333 secondes.
- **Archive conservée : `espresso-source.mp4`.** Ancien rendu CGI Blender ; il ne constitue pas la source de la séquence publique après l'import de la vidéo réelle.

L'extrait réel 0–22,5 secondes a été importé en 160 photogrammes desktop 1280×720 et 160 photogrammes mobile 800×450, avec posters et manifeste, dans `public/espresso-frames/`. Le moteur Canvas/GSAP utilise ces fichiers locaux ; il ne charge pas le MP4 dans le navigateur.

L'auteur du tournage et la licence ne sont pas renseignés. Le dépôt GitHub confirme la provenance de l'envoi, sans établir l'identité de l'auteur de la vidéo ni sa licence.

Voir [le guide de la source réelle](README-LIVE-ACTION.md) et [la provenance détaillée](../reports/live-action/source-provenance.json). Les rapports antérieurs indiquant une source absente décrivent l'état avant son ajout.
